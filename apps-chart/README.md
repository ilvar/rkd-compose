# Applications Helm Chart for Rancher

This Helm chart is configured to work as a Rancher app, allowing easy deployment and management through the Rancher UI.

## Included Applications

This chart includes the following applications, organized by category:

### DNS & Networking
- **Blocky** - DNS server with ad-blocking capabilities

### Management & Monitoring
- **Portainer** - Container management UI
- **Compote** - Docker management dashboard with CapRover integration
- **Kuma (Uptime Kuma)** - Uptime monitoring dashboard
- **Changes** - Website change detection and monitoring

### Media & Entertainment
- **Jellyfin** - Media server for streaming movies, TV shows, and music
- **Jackett** - Torrent indexer
- **Radarr** - Movie collection manager
- **Deluge** - BitTorrent client
- **Immich** - Self-hosted photo and video backup solution

### Productivity & Collaboration
- **Nextcloud** - File sharing and collaboration platform (includes MariaDB database)
- **Paperless** - Document management system (includes Redis)
- **Hoarder** - Web scraping and automation tool (includes Chrome and Meilisearch)
- **Miniflux** - RSS feed reader (includes PostgreSQL database)
- **Archive** - Archive application

### Home Automation
- **Home Assistant** - Home automation platform

### Development & Tools
- **Bugsink** - Bug tracking and issue management
- **IT-Tools** - Collection of useful IT tools

### Web Applications
- **RKD.PW** - Main website (rkd.pw, www.rkd.pw)
- **Blog** - Blog application
- **Irish Schools** - Irish Schools application

## Rancher-Specific Files

### questions.yaml
Defines the form fields that appear in Rancher's UI when installing the app. Users can:
- Enable/disable individual applications
- Configure hostnames for ingress
- Set passwords and secret keys
- Adjust resource limits

### app-readme.md
Documentation displayed in Rancher's app catalog. Provides:
- Overview of all applications
- Prerequisites
- Installation instructions
- Configuration guidance

### Chart.yaml
Contains Rancher-specific annotations:
- `catalog.cattle.io/display-name`: Name shown in Rancher
- `catalog.cattle.io/certified`: Certification status
- `catalog.cattle.io/namespace`: Default namespace

## Deploying to Rancher

### Option 1: Git Repository (Recommended)

1. **Push chart to Git repository:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin <your-git-repo-url>
   git push -u origin main
   ```

2. **Add repository in Rancher:**
   - Navigate to **☰ > Cluster Management**
   - Select your cluster → **Explore**
   - Go to **Apps > Repositories**
   - Click **Create**
   - Choose **Git Repository**
   - Enter repository URL
   - Set branch (usually `main` or `master`)
   - Click **Create**

3. **Install the app:**
   - Go to **Apps > Charts**
   - Find "Applications Chart"
   - Click **Install**
   - Configure using the form
   - Click **Install**

### Option 2: Helm Chart Repository

1. **Package the chart:**
   ```bash
   helm package apps-chart
   ```

2. **Create index:**
   ```bash
   helm repo index .
   ```

3. **Host the repository:**
   - Serve via HTTP/HTTPS (GitHub Pages, S3, etc.)
   - Or use a Helm chart repository service

4. **Add to Rancher:**
   - Go to **Apps > Repositories**
   - Click **Create**
   - Choose **http(s) URL to an index generated by Helm**
   - Enter repository URL
   - Click **Create**

5. **Install the app:**
   - Go to **Apps > Charts**
   - Find "Applications Chart"
   - Click **Install**

## Customization

### Updating questions.yaml

To add new configuration options:
1. Add a new question entry
2. Reference the value path in `values.yaml`
3. Set appropriate type (boolean, string, password, etc.)
4. Group related questions together

### Modifying Default Values

Edit `values.yaml` to change default configurations. These will be used if users don't override them in the Rancher form.

### Adding Applications

1. Add application configuration to `values.yaml`
2. Create deployment/service/ingress templates
3. Add questions to `questions.yaml` for user configuration
4. Update `app-readme.md` with application details
5. Update this README.md to include the new application in the list above

## Testing

Before deploying to Rancher, test the chart locally:

```bash
# Validate chart
helm lint apps-chart

# Dry run
helm install test-apps apps-chart --dry-run --debug

# Test template rendering
helm template test-apps apps-chart
```

## Troubleshooting

### Chart not appearing in Rancher
- Verify repository is properly added
- Check Chart.yaml has correct metadata
- Ensure questions.yaml is valid YAML

### Installation fails
- Check cluster resources
- Verify ingress controller is installed
- Review pod logs: `kubectl logs -l app=<app-name>`

### Questions not showing
- Validate questions.yaml syntax
- Ensure variable paths match values.yaml structure
- Check Rancher version compatibility

## Versioning

When updating the chart:
1. Update `version` in Chart.yaml
2. Update `appVersion` if needed
3. Tag Git repository with version
4. Update chart repository index
